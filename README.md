# رحلة الدكتوراه في علوم الحاسب

موقع تعليمي عربي خفيف ومباشر يساعد على الاستعداد لدكتوراه علوم الحاسب عبر:

- صفحة رئيسية تعرف بالتخصص والمجالات.
- صفحات تفصيلية للمجالات الأساسية في الخطة.
- قاموس مصطلحات إنجليزية مع نطق صوتي.
- بنية قابلة للتوسع بإضافة الدروس لاحقًا بناء على الأسئلة.

## التشغيل

يمكن تشغيل الموقع بأي خادم ملفات ثابتة. مثال:

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

ثم افتح:

`http://localhost:4173`

## النشر المجاني التلقائي

تمت إضافة ملف نشر تلقائي عبر GitHub Pages:

`/.github/workflows/deploy-pages.yml`

الفكرة بسيطة:

- ترفعين المشروع مرة واحدة إلى GitHub.
- تفعّلين GitHub Pages من إعدادات المستودع.
- بعد ذلك أي `git push` إلى فرع `main` سيؤدي إلى `deploy` تلقائيًا مجانًا.

### الخطوات لأول مرة

1. أنشئي مستودعًا جديدًا في GitHub.
2. افتحي الطرفية داخل هذا المجلد.
3. نفّذي الأوامر التالية بعد استبدال الرابط برابط مستودعك:

```bash
git init
git add .
git commit -m "Initial doctoral prep site"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

4. في GitHub:

- ادخلي إلى `Settings`
- ثم `Pages`
- واجعلي المصدر `GitHub Actions`

بعدها سيبدأ النشر التلقائي مع كل تحديث جديد.

### بعد ذلك

كلما عدّلت أنا الموقع لك، يكفيك:

```bash
git add .
git commit -m "Update lessons and content"
git push
```

وخلال دقائق سيتحدث الموقع على الإنترنت تلقائيًا.

## التوسعة لاحقًا

كل محتوى الموقع الحالي موجود داخل الملف `app.js`.

عندما ترسلين سؤالًا جديدًا عن مجال معين، يمكننا:

1. إضافة درس جديد داخل نفس المجال.
2. ربطه من صفحة المجال.
3. توسيع القاموس والمصطلحات.
